# Question.md 模板

`Question.md` 用于记录最终报告合并过程中发现、但当前任务不允许或不适合立即补证的问题。它是后续分析任务的输入，不是最终报告正文的一部分。

## 触发条件

出现以下任一情况时，应生成或更新 `Question.md`：

1. 语义不详。
2. 数据冲突。
3. 逻辑或流程冲突。
4. 逻辑链路不完整。
5. 分析不够详细或缺少关键证据。
6. 技术方案或功能未说明白。

## 问题格式

```md
# 待补充分析问题

## Q-001：问题标题

| 字段 | 内容 |
|---|---|
| 问题类型 | 语义不详 / 数据冲突 / 逻辑或流程冲突 / 逻辑链路不完整 / 分析不够详细或缺少关键证据 / 技术方案或功能未说明白 |
| 涉及主题 | 初始化 / 配置 / 网络 / Hook / native / 其他 |
| 涉及来源 | 报告路径、代码位置、日志位置、请求位置或证据文件 |
| 当前已有说法 | 概括已有材料中的说法 |
| 问题详情 | 写清哪里不清楚、哪里冲突、哪里缺证据 |
| 影响范围 | 说明影响最终报告哪个结论或章节 |
| 建议补充分析 | 说明需要补代码、补抓包、补 Hook、补字段解释还是补流程链路 |
| 优先级 | 高 / 中 / 低 |
```

## 记录要求

1. 每个问题必须有明确来源。
2. 每个问题必须说明为什么影响最终报告。
3. 每个问题必须给出后续可执行的补充分析方向。
4. 不写开发修复建议。
5. 不写安全、隐私、风险、合规等审计式评价。
