# 证据索引规范

最终报告必须包含证据索引，用于让读者回查每个核心结论的来源。

## 字段

| 编号 | 结论 | 来源文件 | 证据类型 | 证据位置 | 是否已在正文引用 |
|---|---|---|---|---|---|

## 证据类型

证据类型只能使用可回查来源，例如：

- 反编译代码。
- smali 代码。
- 抓包数据。
- Hook 日志。
- 配置文件。
- 解密数据。
- native 函数、字符串、交叉引用或伪代码。
- 普通分析报告或阶段报告结论。

## 使用规则

1. 核心结论必须进入证据索引。
2. 证据位置必须能回到具体文件、类、方法、请求、日志或报告章节。
3. 如果正文已经贴出关键证据，索引中仍需记录。
4. 如果只在索引中引用辅助证据，正文应至少说明该证据支撑什么结论。
5. 不得用占位代码、示例数据或未经确认的伪代码冒充证据。

## 代码引用控制

最终报告中，核心链路和关键判断必须附代码片段或原始证据片段。相同逻辑多处出现时，可只贴一次完整证据，其他位置引用证据索引。

禁止：

1. 删除核心证据。
2. 只写结论不写来源。
3. 只贴代码不解释。
4. 使用占位代码。
5. 使用未经确认的示例数据冒充抓包、日志、配置或解密结果。
