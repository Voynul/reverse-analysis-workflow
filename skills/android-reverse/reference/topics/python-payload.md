# Android 目标中的 Python 载荷

仅在任务证据指向 APK 内嵌 Python、pyc/pyz、Chaquopy/Kivy 类运行时或关联 Python 载荷时使用，不触发普通 Python 源码开发或通用桌面逆向。

## 确认载荷

结合包结构、加载代码、扩展模块、文件头和实际入口区分源码、归档、字节码、解释器与包装器。文件高熵或某个标签不足以确认保护形式。

Python 版本、字节码、marshal/code object 布局和保护器版本共同影响解析。记录真实格式信息；工具无法识别不能直接判加密或损坏。

## 可选恢复

- 可读代码、字符串、导入与 native 交接先用于回答问题，不要求先解包全部内容。
- 载荷有包装、加密或转换时，从真实加载与消费路径定位格式、长度及转换参数；不复制案例中的 key schedule、TLV 类型、偏移或 nonce。
- 使用静态解析、最小隔离执行、原函数调用或 native 分析按依赖选择。加载 marshal、反序列化或执行不可信代码需要合适隔离，不把普通 REPL 当安全沙箱。
- 扩展段、字符串表、嵌套 code object 及异常元信息可能独立处理，恢复某层不等于整个程序完整。

## 验证

区分解析得到的字节码、反编译文本、可执行模块及业务输出。重组后核对版本、结构与目标行为；仅能在特定环境调用时说明依赖。
