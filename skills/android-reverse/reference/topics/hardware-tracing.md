# 硬件观察、采样与轨迹差分

需要内存访问、控制流或崩溃前路径证据时，可比较软件、调试和硬件方法。硬件特性是否存在、能否访问和输出能否正确解码是独立条件，不默认当前设备支持。

| 方法 | 能帮助回答 | 重要边界 |
|---|---|---|
| 硬件观察点 | 谁访问指定地址、访问时的上下文 | 槽位、长度/对齐、线程与地址生命周期；ptrace 方式仍可暴露调试状态 |
| ETE/相关执行轨迹与收集缓冲 | 某次执行的分支路径、两次运行差异 | 生产端、缓冲、解码器、缺包与时间关联，不是自动的寄存器全量记录 |
| SPE 类采样 | 哪些代码与数据地址发生关联 | 采样不是每次访问完整记录，支持与权限需验证 |
| BRBE/分支记录类能力 | 崩溃前或某时刻的有限分支线索 | 有限深度、线程、覆盖与读取时机，不能当完整调用栈 |
| 地址符号化 | 运行地址对应模块、符号和静态位置 | ASLR、段布局、文件偏移、strip 和最近符号不等于精确函数 |

## 校准与采集

先用任务范围内的控制数据确认实际可命中、地址空间正确和记录能送达。特性名称、生成的控制寄存器值或成功编译不能代替设备结果。

限定进程、线程、窗口和数据；明确暂停、采样与异常处理对目标的影响。地址可能来自栈、对象移动、释放后复用或库更新，不能持续使用过期位置。

## 差分与解释

两次运行先对齐模块版本、相对地址、输入与时间范围，识别初始化、线程调度和重复循环噪声。不同基本块可能与目标条件有关，但差分本身不构成因果关系。

丢事件、缓冲覆盖、部分解码或不同采样率会制造差异。保留原始轨迹及解码条件，必要时使用重复运行或已有控制点交叉验证。

崩溃线索结合信号、故障地址、模块、线程与生命周期解释。符号化结果、有效命中和已证明业务效果分别报告。

本技能已迁入离线符号化、差分和切片辅助，未迁入硬件生产端。操作见 [离线工具](../tools/offline.md)、[专项工具](../tools/specialists.md)，解释器语义见 [VM](../vm-protection.md)。
