# 离线工具、索引器与解析脚本

这些工具是可选实现；已有 MCP 能可靠回答问题时可以直接使用。命令路径相对技能根目录解析，不相对用户项目，也不假设 Python 在固定目录。执行前查看对应 `--help`，只在需要该能力时调用。

部分脚本使用 Python 3.10+ 的类型语法，应选择兼容解释器。本次回归环境为 Windows / Python 3.13；其他解释器和系统的运行结果不由本次测试代替。

## 已迁入的离线辅助脚本

| 文件（位于 `scripts/offline/`） | 输入/用途 | 输出边界 |
|---|---|---|
| `js_obf_detect.py` | JS 文本、家族线索、残留特征 | 启发式候选与建议顺序，不是 AST 重写器或 VMP 判决器 |
| `jsvmp_loader_decode.py` | 明确的 Base64/hex/字节输入 | 支持的 varint/ZigZag 链，不是任意 JSVMP 解码器 |
| `kotlin_name_recovery.py` | 已有反编译源码 | 候选名称映射；需要显式新输出目录，不自动批量重命名 |
| `blob_decode.py` | 编码值或明确指定的 XML 键 | 编码、旋转和压缩候选；结构看似合理不证明语义 |
| `protobuf_decode_raw.py` | 二进制/hex 或解码 JSON | 无 schema 的线结构与再编码；字段类型和嵌套存在歧义 |
| `trace_addr2sym.py` | ELF、明确的地址空间与地址列表 | 映射和符号近似；不是完整反汇编或函数执行证明 |
| `trace_diff.py` | 兼容格式的两份轨迹 | 差异与统计；缺失事件影响结论 |
| `vm_handler_slice.py` | 轨迹及可选分发器/映射 | 切片和聚类候选，不自动恢复全部语义 |
| `apk_diff.py` | 两份 APK | 条目内容与压缩方式差异；不是完整归档或安装验证器 |
| `dexutil.py` | DEX 文件或归档中的明确条目 | 基础解析库与有限结构检查，不是官方 verifier |
| `dex_strings.py` | DEX/APK/明确目录 | 字符串与类表；显示限制不代表全量命中 |
| `dex_classdiff.py` | 两份 DEX | 类集合、标志差异；不能证明方法语义一致 |
| `dex_find_insn.py` | 指定 DEX、类/方法和语义过滤 | 有限解码器的候选位置；不完整解码时交叉核对 |
| `dex_dump_validate.py` | 明确的 dump 文件/目录 | 结构、内容和去重线索；评分不等于最佳载荷或真实保护类型 |
| `java2c_probe.py` | APK/DEX/ELF | native 密度、符号等形态指标；不以阈值代替 JNI 绑定证据 |

各脚本的 flags 和格式以随附代码为准，不用同名上游的新版本参数猜测。本技能未迁入任意设备读写、内核注入或自动下载安装器。脚本继承的算法与格式边界参照各自说明；维护测试只证明被测样本与分支。

归档工具若默认只取一个 DEX，应显式选择并覆盖相关成员；不能以首个成员代表整个安装集合。部分解析器采用启发式或容错解码，保留原输入和转换过程后再解释结果。

## 使用时的输入输出

先确认目标、所需字段和输出量。需要文件输出时指定独立位置；有输入重写或裁剪选项时先理解其行为，不在原始证据上执行。读取私有值不意味着可以将其完整打印到对话。

可用脚本的 `--help`、内嵌自测及隔离回归测试不需要真实目标。运行维护测试不会连接手机或替代实际任务验收；维护入口见 `../../maintenance/validate_skill.py`。

维护时可在具备 pytest 的隔离解释器中运行 `maintenance/run_tests.py`；它禁用无关全局插件，不自动安装依赖。结构检查和回归测试不属于 Agent 每次任务的启动步骤。

## 外部索引、SQL 与解析工具

droidasc、rasc、ddc、dexsql、smali/baksmali、DEX 专用库或 JS AST 工具可以作为候选。按当前问题比较：

- 类、字符串、调用引用和单方法读取；
- 跨表关联、聚合、数值常量、注解或资源查询；
- 是否能限定一个 DEX、是否覆盖全部 split 和是否有截断；
- 输出来源、解析完整性、版本与可复查位置。

CLI 和 MCP 都可以使用，工具支持 SQL 时先读取实际表结构；不猜表名或把自建索引当原始实现。AST 重写需要真正的 parser/traverser/generator；正则检测结果不能当 AST 事实。缺少依赖时选择替代路线或报告受影响部分，不把安装工具设为普遍前提。
