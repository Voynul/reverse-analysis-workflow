# 运行时解析、模拟执行与高级观测工具

仅在目标和问题需要时选择某一类，不预检全部工具，也不把这里的候选名称当已安装清单。运行目标的身份、格式和能力验证独立于经验方法选择。

## Dart 与 Unity

snapshot 前端、IL2CPP 解析器、CIL/C# 分析器及运行时桥接工具按实际格式和版本选择。核对输入配对、ABI 和输出类型：对象池、声明骨架、函数地址、反汇编和运行对象不是同一种证据。

加载导入脚本前读取其内容、参数和依赖，确认操作当前分析数据库；JSON 和头文件是数据，不直接执行。工具未提供无头接口时，可选等价工具或提供人工协作路线，不默认接管 GUI。

## 模拟执行、RPC 与远程调试

Unicorn、unidbg、可用调试器或原函数 RPC 按依赖选择，不默认构建某个工具。明确初始化、寄存器/调用约定、外部调用、时间、随机数和跨调用状态。

远程调试匹配实际进程 ABI 与服务器接口；只在授权设备上开放必要本地转发。无法暂停、附加或命中断点时先核对进程状态和映射，不推导不存在对应代码。

## 软件轨迹与硬件观测

Stalker、QBDI、硬件观察点、CoreSight/ETE、SPE/BRBE、perf 或内核工具均为候选能力，不承诺设备支持或目标不可检测。

先确认所需观测是调用、分支、指令、数据访问还是状态改变，再核对对应生产端、权限和解码器。生成器、自测或成功编译不能证明设备采集可用。使用有限控制样本验证消息链路与地址空间后，再解释目标记录。

本次未迁入上游设备注入器、内核模板和硬件采集驱动；需要这类实现时依当前任务选择并单独验证，不能使用不存在的本地脚本路径。
