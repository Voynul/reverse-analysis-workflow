# 无头 native 工具操作

仅在选择 native 分析工具后读取；方法见 `../native-analysis.md`。`idalib-mcp` 可用时优先使用，缺失时可以选择实际可用的等价无头能力。

## 打开与查询

- `idb_open` 显式选择 `mode="force_headless"`，以选定文件或已确认来源的关联二进制打开，不探测或接管 GUI。
- 使用打开返回的 database/session；已有会话可用 `idb_list` 核对。必要时做一次健康检查并等待实际自动分析状态。
- 新目标先用 `survey_binary` 取得概览，再根据问题读取字符串、导入、交叉引用、函数和数据；不为侦察反复拉取完整函数表。
- 函数伪代码不是最终语义保证。存在类型、边界或间接调用歧义时检查反汇编和引用。
- 类型或名称变化后，如服务存在反编译缓存，按工具要求使缓存失效后再读。数字、地址换算使用可审计计算，不复制别处的绝对地址。
- 大结果采用范围、字段和分页限制，不以工具结果被截断作为未命中。

## 状态与保存

session 与 APK 不强制一一对应。需要恢复时记录二进制身份、用途、会话标识和保存位置；简单分析不要求新增状态文件。

数据库内命名、类型和注释是分析辅助，不等于修改用户原始二进制。要保留成果时调用实际保存接口，并确认输出位置。

无头 worker 生命周期由服务管理；`idle_ttl_sec` 等参数只按当前实现使用，不通过系统命令终止其他会话的进程，也不将闲置时长当退出保证。
