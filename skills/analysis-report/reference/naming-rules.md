# 名称俗语化

## 核心目标

把行业术语、英文缩写、内部黑话转换成普通读者能理解的说法。优先解释“它有什么用”，而不是堆叠原始名称。

## 执行规则

1. 标题、小节名、图表节点优先使用中文白话。
2. 正文先解释作用，再补充原始技术名。
3. 不用另一个专业词解释专业词。
4. 改写后要短、准、直白。
5. 无法替换的技术词，第一次出现时加白话解释。
6. 不得为了白话化改变代码含义。

## 示例

| 原表达 | 推荐表达 |
|---|---|
| eCPM | 每展示一次预估能赚多少钱 |
| UMP Consent | 用户授权弹窗 |
| Waterfall | 按顺序尝试多个广告源 |
| Token | 文字片段或身份片段，具体含义以代码为准 |
| Bidding | 比价 |

代码位置、字段名和 URL 仍保留原文。
