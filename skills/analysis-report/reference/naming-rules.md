# 名称俗语化

## 核心目标

把行业术语、英文缩写、内部黑话转换成普通读者能理解的说法。优先解释“它有什么用”，而不是堆叠原始名称。

## 执行规则

1. 标题、小节名、图表节点优先使用中文白话。
2. 正文先解释作用，再补充原始技术名。
3. 不用另一个专业词解释专业词。
4. 改写后要短、准、直白。
5. 无法替换的技术词，第一次出现时加白话解释。
6. 不得为了白话化改变代码含义。
7. 术语白名单中的词可以直接使用，不强制俗语化；但仍需结合上下文说明具体策略或证据，不能用术语替代结论。

## 术语白名单

以下术语面向目标读者可直接使用：

- Cloaking
- eCPM
- UMP

白名单术语如果是字段名、接口名、配置名或代码原文，应保留原文；如果是报告结论中的策略名称，应说明它具体影响了什么行为，例如广告显示隐藏、展示次数、展示频率、Ad ID 或广告源选择。

## 非白名单术语示例

| 原表达 | 推荐表达 |
|---|---|
| Waterfall | 按顺序尝试多个广告源 |
| Token | 文字片段或身份片段，具体含义以代码为准 |
| Bidding | 比价 |

代码位置、字段名和 URL 仍保留原文。
