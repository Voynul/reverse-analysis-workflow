# 报告图表规范

## 触发条件

涉及以下内容时必须配图：

- 调用链。
- 数据流。
- 决策分支。
- 网络请求时序。
- 状态切换。
- 模块关系。

## 图表类型

| 场景 | 图表 |
|---|---|
| 调用链、依赖关系、决策分支 | `flowchart TD` |
| 数据流转、来源链路 | `flowchart TD`，可用 `subgraph` |
| 网络请求、回调、异步交互 | `sequenceDiagram` |
| 状态切换 | `stateDiagram-v2` |

## 节点命名

图表节点必须使用简短中文描述，说明该步骤在做什么。

推荐：

- 读取本地缓存。
- 请求服务器配置。
- 判断今天是否还能展示。
- 按金额从高到低排序。

避免：

- `getConfig()`
- `BiddingComparator`
- `a.b.c()`
- 原始混淆字段名。

## 编号要求

- 图表编号使用 `图 1`、`图 2`。
- 表格编号使用 `表 1`、`表 2`。
- 正文必须引用图表编号。

## 证据要求

流程图中的关键分支、开关、排序、状态切换必须在正文中附代码、抓包、Hook 或 native 证据。
